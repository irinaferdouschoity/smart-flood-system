# data/ folder

| Item | What it is | Needed? |
|---|---|---|
| `bangladesh_districts.csv` | 64 districts: division and centre coordinates (approximate) | yes |
| `upstream_stations.csv` | 6 upstream rainfall points in India | yes |
| `flood_labels/bd_flood_events.csv` | sourced flood events = the labels | yes (edit to improve) |
| `flood_labels/bd_district_flood_labels.csv` | generated by `python -m floodml labels` | generated |
| `power_daily/` | NASA POWER downloads, one CSV per point (`python -m floodml download`) | generated (~50 MB) |
| `bd_district_training_dataset.csv` | **the full dataset**: features + flood days per district per day | generated |
| `city_specific_risk.csv` | weather + thresholds for the 6 city dashboard | city dashboard |
| `imerg_downloads/` | optional raw IMERG files (your old ~1 GB) - not used by the model | no |

Everything marked "generated" can be deleted and rebuilt. The dataset CSV can be opened in Excel
(columns: `district, division, date, rain_*, soil_*, temp, ..., flooded, label_status, event_id, flood_type`).

The same daily data can be exported to MySQL (`python -m floodml export-mysql`, tables `bd_*`) - see the main README.
